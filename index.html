Primal

Official PlayStation 2 Website Archive (2003)

Reconstruction of surviving material from the original Flash-based site (primalgame.com).
Powered by Ruffle Flash emulator. For archival / preservation purposes.

What survived: Intro cinematic, English hub + realm HTML shells, and several VIP-area SWFs (tarot, downloads, secrets, etc.).
What is missing: The main interactive hub SWF, the six realm SWFs, character bios, the full VIP welcome experience, and the four US mini-games. Those assets were never captured by the Wayback Machine.

4. How to use / host this archive

  1. Open index.html in any modern browser (Chrome, Firefox, Edge, Safari). Ruffle loads automatically from CDN.
  2. To host online: upload the entire primal_ps2_archive folder to any static host (GitHub Pages, Netlify, Cloudflare Pages, Neocities, your own server, etc.). No backend required.
  3. For fully offline use: the Ruffle script is loaded from unpkg.com. If you need pure offline, download the Ruffle self-hosted package from ruffle.rs and place it in an ruffle/ subfolder, then change the script src.
