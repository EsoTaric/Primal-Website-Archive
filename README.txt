Primal (PS2, 2003) Official Website – Archival Reconstruction
============================================================

This package contains the surviving material recovered from the Internet Archive
Wayback Machine for the original official site:

  http://www.primalgame.com/

Contents
--------
- index.html          Modern entry page with Ruffle Flash emulator
- intro/intro.swf     Opening cinematic (works)
- hub/                English main hub HTML shell
- realms/             Six realm HTML shells (Aetha, Aquis, Solum, Volca, Mortalis, Nexus)
- vip/                VIP area HTML + surviving SWFs (tarot, downloads, secrets, border, etc.)
- landing.html        Original landing page capture

What is missing (never archived)
--------------------------------
- Main interactive hub SWF (oblivion_en.swf)
- All six realm interactive SWFs
- Full VIP welcome experience
- Character / enemy bios that lived inside Flash
- The four US PlayStation OGS mini-games
- Most video and deep internal assets

How to use
----------
1. Open index.html in any modern browser.
2. The intro should play automatically via Ruffle (loaded from CDN).
3. VIP SWFs can be opened individually.
4. Original HTML shells are included for completeness but will not show the missing Flash content.

Hosting online
--------------
Upload the entire primal_ps2_archive folder to any static web host:
  - GitHub Pages
  - Netlify
  - Cloudflare Pages
  - Neocities
  - Any ordinary web hosting / S3 / etc.

No server-side code is required.

For fully offline use, download the self-hosted Ruffle package from https://ruffle.rs
and adjust the <script> tag in index.html.
